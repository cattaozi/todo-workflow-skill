# Room 稳定 UI 基线

本目录保存 `projects/room/` 的版本化 UI 资产和结构门禁。账本是事实源，Room 是展示层；账本刷新只能改变数据，不得顺带重写 UI。

## 资产

- `room.css`：用户已经确认的视觉基线。
- `room.js`：用户已经确认的本地复制、视图切换、搜索与状态筛选交互。
- `verify_room.py`：比较版本化资产与运行时资产，并检查关键页面结构。

## 两种变更模式

### 数据刷新（默认）

允许修改：事实文字、数字、状态属性、链接、数据行、详情正文和更新时间。

禁止修改：`room.css`、`room.js`、导航、工具栏、表格列、类名、DOM 骨架和本目录资产。

刷新前后都执行：

```bash
python3 skills/room-assets/verify_room.py
```

任一 UI 资产或结构检查失败，都必须停止并修复；不能用本轮生成物覆盖基线。

### UI 变更（仅用户明确要求时）

先修改本目录基线和结构契约，再同步 `projects/room/` 运行时资产，最后完成页面视觉与交互验证。账本变化本身不构成 UI 变更授权。
